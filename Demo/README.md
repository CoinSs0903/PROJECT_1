## 🚀 HƯỚNG DẪN BIÊN DỊCH RA FILE PDF HOÀN CHỈNH

### Cách 1: Sử dụng Overleaf (Khuyên Dùng — Nhanh & Đẹp Nhất)
1. Truy cập [https://www.overleaf.com](https://www.overleaf.com) và đăng nhập.
2. Tạo dự án mới: **New Project** $ightarrow$ **Blank Project** (đặt tên `Project1_Software_Design_Dossier`).
3. Tải file `Software_Design_Dossier_PROJECT_1.tex` lên.
4. Chọn Compiler: Vào **Menu** (góc trái trên) $ightarrow$ chọn **pdfLaTeX** hoặc **XeLaTeX**.
5. Bấm nút **Recompile** để xem trước và tải về file PDF sắc nét.

### Cách 2: Sử dụng MiKTeX / TeXworks trên máy tính cá nhân
1. Mở file `.tex` bằng ứng dụng **TeXworks** hoặc **VS Code (LaTeX Workshop)**.
2. Chọn trình biên dịch `pdfLaTeX`.
3. Bấm nút **Build / Compile** (Ctrl + T trong TeXworks).
