# 🎨 Frontend Source Code Directory

Thư mục lưu trữ mã nguồn giao diện người dùng (Client-side Web / Mobile Application).

### Cấu Trúc Khuyến Nghị:
- `src/assets/` : Hình ảnh, icon, fonts, css toàn cục.
- `src/components/` : Các UI components tái sử dụng (Button, Modal, Table, InputField,...).
- `src/layouts/` : Layout chính (Sidebar, Header, Footer, AdminLayout).
- `src/pages/` : Các trang giao diện ứng với từng màn hình chức năng.
- `src/services/` : Các hàm gọi API đến Backend (Axios client, API endpoints).
- `src/store/` : Quản lý trạng thái ứng dụng (Global State Management).
- `src/utils/` : Hàm tiện ích định dạng tiền tệ, ngày tháng, validate input.
